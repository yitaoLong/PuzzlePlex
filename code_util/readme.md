# Code Processing Pipeline

This provides a pipeline to process and execute code outputs generated by foundation models for solving puzzles.

## Step-by-Step Instructions

### 1. Extract Code from Model Outputs

After obtaining the code responses from each model for each puzzle, begin by running:

    python3 extract_code.py

This script extracts Python code enclosed within triple backticks (` ```python``` `) from the model outputs. It handles cases where the code block was not correctly extracted during the initial generation.

### 2. Identify Missing Package Dependencies

Once the code has been extracted, run the following script:

    python3 get_code_import_modules.py

This script analyzes the extracted code files and identifies any imported packages that are not currently installed in your environment.

### 3. Install Missing Packages

Based on the output from the previous step, install any missing dependencies to ensures that all required libraries are available, preventing import errors when running the code to play and evaluate the puzzles.
